# NamVoy

AI-powered reverse travel marketplace.

## MVP v0.1

NamVoy lets travelers create travel requests and receive competing offers from verified travel providers.

### Core flow

Traveler → Travel Request (RFQ) → Provider Bid → Compare Bids → Booking

## Technology

- PHP 8.x
- MySQL / MySQLi
- HTML5 / CSS3 / JavaScript
- Bootstrap 5
- AJAX / Fetch API

The initial implementation intentionally avoids PHP frameworks and PDO.

MVP foundation in progress.
